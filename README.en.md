# Knowledge Validation - Introduction to Machine Learning

This repository contains a project developed to validate basic Machine Learning knowledge. The **Melbourne Housing Market** dataset is used to predict house prices based on various features.

## Project Content

The analysis and modeling can be found in the `validation-knowledges-intro-ml.ipynb` file, which includes:
1.  **Descriptive Analysis**: Correlation visualization using scatter plots with `seaborn` and `matplotlib`.
2.  **Data Preprocessing**: Feature selection and categorical variable encoding using `scikit-learn`'s `OrdinalEncoder`.
3.  **Model Creation**: Implementation of a regression model based on decision trees (`DecisionTreeRegressor`).
4.  **Model Validation**: Performance evaluation using Mean Absolute Error (MAE).

## Libraries Used

*   `numpy`
*   `pandas`
*   `seaborn`
*   `matplotlib`
*   `scikit-learn`
