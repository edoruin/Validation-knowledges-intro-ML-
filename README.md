# Validación de Conocimientos - Introducción a Machine Learning

Este repositorio contiene un proyecto desarrollado para validar conocimientos básicos de Machine Learning. Se utiliza el conjunto de datos de **Melbourne Housing Market** para predecir los precios de las viviendas basándose en diversas características.

## Contenido del Proyecto

El análisis y modelado se encuentran en el archivo `validation-knowledges-intro-ml.ipynb`, el cual incluye:
1.  **Análisis Descriptivo**: Visualización de correlaciones mediante gráficos de dispersión utilizando `seaborn` y `matplotlib`.
2.  **Preprocesamiento de Datos**: Selección de características y codificación de variables categóricas utilizando `OrdinalEncoder` de `scikit-learn`.
3.  **Creación del Modelo**: Implementación de un modelo de regresión basado en árboles de decisión (`DecisionTreeRegressor`).
4.  **Validación del Modelo**: Evaluación del rendimiento utilizando el Error Absoluto Medio (MAE).

## Bibliotecas Utilizadas

*   `numpy`
*   `pandas`
*   `seaborn`
*   `matplotlib`
*   `scikit-learn`
